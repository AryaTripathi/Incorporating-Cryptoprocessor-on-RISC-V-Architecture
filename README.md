# Incorporating-Cryptoprocessor-on-RISC-V-Architecture
This project integrates a cryptoprocessor onto the RISC-V architecture, enabling encryption and decryption capabilities within the computational core. At its core, the RISC-V processor executes the R-type instructions. To enhance its capabilities, a Blowfish-64 cryptoprocessor module is introduced to handle the encryption and decryption tasks
