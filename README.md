# Incorporating-Cryptoprocessor-on-RISC-V-Architecture
This project integrates a cryptoprocessor onto the RISC-V architecture, enabling encryption and decryption capabilities within the computational core. At its core, the RISC-V processor executes the R-type instructions. To enhance its capabilities, a Blowfish-64 cryptoprocessor module is introduced to handle the encryption and decryption tasks. A custom instruction has been defined for the same. This ensures that there is minimal disruption to its inherent functionality. A modular approach supports the design philosophy, enabling the RISC-V core to maintain its execution flow while the cryptoprocessor encrypts and decrypts the data.  This communication between the processor and the cryptographic module is taken care of by the AXI Lite interface ensuring efficient communication and data exchange. The project unfolds in two phases: RTL design in Verilog HDL and physical implementation utilizing the OpenLane software suite. The RTL phase crafts the digital blueprint of the interaction between the RISC-V processor and the cryptoprocessor module. Meanwhile, the physical design is responsible for the physical representation of the envisioned architecture.
